## 📌 Context & Overview
**Project Name:** AI, Data Science & Statistics Global Career & Open Data Dashboard  
**Objective:** สร้าง Single-Page Interactive Web Dashboard (HTML/CSS/JavaScript) เพื่อแสดงข้อมูลเชิงลึกเกี่ยวกับตลาดแรงงาน สายงาน AI, Data Science และ Statistics โดยอาศัยข้อมูลจากแหล่ง Open Data ระดับโลก

## 🎨 UI/UX Requirements & Functional Features

1. **KPI Highlights (Top Cards):**
   * Average Entry Salary ($70k USD)
   * Projected Job Growth Rate (+35% in 10 years)
   * Total Open Datasets Available
   * Top Hiring Country (United States, United Kingdom, Germany, Singapore)

2. **Interactive Filters:**
   * Filter by **Field:** `[ All | Artificial Intelligence | Data Science | Statistics ]`
   * Filter by **Experience Level:** `[ All | Entry-Level | Mid-Level | Senior / Lead ]`
   * Filter by **Region:** `[ Global | North America | Europe | Asia-Pacific ]`

3. **Core Interactive Modules:**
   * **Module A: Salary & Career Estimator Calculator**  
     ให้ผู้ใช้เลือก Degree + Experience Level + Target Role เพื่อคำนวณช่วงเงินเดือนโดยประมาณและแสดง ทักษะที่ต้องมี (Required Skills Checklist).
   * **Module B: Interactive Skill Matrix Checklist**  
     Checklist ทักษะแยกตามสายงาน ให้ผู้ใช้ติ๊กเลือกทักษะที่ตัวเองมีเพื่อประเมิน readiness score (0 - 100%).
   * **Module C: Open Data Directory & Download Table (รองรับการ Search & Filter)**  
     ตารางรายชื่อ Open Data พร้อมช่อง Search ค้นหาชุดข้อมูล, ตัวกรอง License (CC0, CC-BY, Public Domain), รูปแบบไฟล์ (`.csv`, `.xlsx`, `.json`), และปุ่ม Direct Download Link ไปยังแหล่งดาวน์โหลดจริง.

## 🛠️ Technical Constraints for Antigravity

1. **Architecture:** Single-file HTML (`index.html`) หรือ Clean Modular Structure ที่มี `index.html`, `styles.css`, `app.js`.
2. **Styling Framework:** **Tailwind CSS** (โหลดผ่าน CDN `https://cdn.tailwindcss.com`).
3. **Icons & Charts:** 
   * Lucide Icons หรือ FontAwesome (ผ่าน CDN).
   * **Chart.js** หรือ **ApexCharts** สำหรับวาดกราฟเปรียบเทียบเงินเดือนและการเติบโตของแต่ละตำแหน่ง.
4. **State Management:** Vanilla JavaScript State Management หรือ lightweight Alpine.js/Vue.js (CDN).
5. **Data Integration:** ฝังชุดข้อมูลเปิด Mock-up JS Array ที่สมจริงอ้างอิงจากแหล่งข้อมูลทั้ง 7 แหล่งข้างต้น ไว้ในตัวโค้ด เพื่อให้ตาราง Open Data Directory และตัวคำนวณทำงานแบบ Client-side Interactive ได้ทันทีโดยไม่ต้องต่อ Backend.
